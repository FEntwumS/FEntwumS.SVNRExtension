# FEntwumS.SVNRExtension
![image](https://github.com/FEntwumS/FEntwumS.SVNRExtension/blob/main/Icon.png?raw=true)

This plugin is an extension for OneWareStudio (OWS), designed to facilitate the conversion of Assembly code into a VHDL file format.

The target architecture is the SVNR (Simple Von Neumann Rechner), a straightforward 16-bit Von Neumann computer designed by the Technical University of Cologne (TH Köln) specifically for educational purposes. 
This tool streamlines the process of translating low-level programs into hardware description language for simulation and implementation, enhancing the learning experience.

## Installation

The extension is not listed in the OneWare Studio store. To install it, add its manifest as a package source once:

1. Open **Settings → Package Manager → Sources**.
2. Add this URL to **Custom Package Sources**:

   ```
   https://raw.githubusercontent.com/FEntwumS/FEntwumS.SVNRExtension/main/oneware-extension.json
   ```

3. Open the extension manager, refresh, and install **SVNR Extension** from the **Tools** category.

Updates are offered through the same source.
